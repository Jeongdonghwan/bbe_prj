# 블로그 자동 발행 루틴 — 실행 지침

클라우드 루틴(하루 2회: 04:00 · 13:00 KST, 각 5편)이 이 문서를 그대로 따른다.
서버는 06:00 · 14:00 에 `scripts/cron.py pull_content` 로 받아가며, 글은 요청 때 파일에서 바로 읽으므로 재시작이 필요 없다.

## 이 사이트

**마이마케팅**(셀프마이마케팅.kr) — 대행사 없이 플레이스 · 스마트스토어 · 쿠팡 마케팅을 직접 하려는 사장님·판매자를 위한 셀프서브 플랫폼.
매체 단가가 공개돼 있고, 크레딧을 충전해 유입 캠페인을 직접 만들며, 등록 즉시 일자별 순위가 기록된다.
**독자는 손님이 아니라 사장님·판매자다.** 글은 "직접 해 보는 방법"을 알려주는 실행 가이드여야 한다.

## 매 실행 순서

1. `content/keyword-cursor.json` 의 `next` 를 읽는다.
2. `content/keywords.json` 에서 `next` 부터 **5개**를 꺼낸다. 각 항목의 `kw` 가 글의 메인 키워드다.
3. 키워드마다 글 1편을 `content/blog/<slug>.md` 로 쓴다.
   - slug = 메인 키워드의 공백을 하이픈으로 (`치과 리뷰 늘리는 방법` → `치과-리뷰-늘리는-방법`). 소문자·숫자·한글·하이픈만.
   - 같은 이름 파일이 이미 있으면 그 키워드는 건너뛰고 다음 항목을 쓴다(5편을 채운다).
4. `python scripts/seo_check.py --blog content/blog/<새 파일들>` 을 실행한다.
   **FAIL 이 하나라도 있으면 그 글을 고쳐서 다시 검사한다.** 통과할 때까지 커밋하지 않는다.
5. `next` 를 꺼낸 개수만큼 올려 `content/keyword-cursor.json` 에 저장한다.
6. `content/` 아래만 커밋한다: `git add content/ && git commit -m "blog: N편 (cursor A→B)"` → `git push origin main`.
   **`content/` 밖의 파일은 절대 수정·커밋하지 않는다.**

## 파일 형식

```
---
title: '60자 이내, 메인 키워드를 앞쪽에'
description: '80~160자. 글이 무엇을 알려주는지 구체적으로'
date: YYYY-MM-DD   (오늘, KST)
keywords: '메인 키워드, 보조 키워드1, 보조 키워드2'
category: 플레이스 | 스마트스토어 | 쿠팡 | 광고 | 리뷰 | 운영
---
(본문 마크다운)
```

- frontmatter 값에 **콜론·쉼표·#** 이 있으면 반드시 작은따옴표로 감싼다(값 안의 작은따옴표는 `''` 두 번). 안 감싸면 검사에서 실패한다.
- 본문에 `# ` (h1) 쓰지 않는다 — 제목이 h1 이다. `##` 소제목 4개 이상, 필요하면 `###`.
- 본문 공백 제외 **1,500자 이상**. 표·목록을 적절히 쓴다.

## 글 원칙 (검사로도 걸러지지만 처음부터 지킬 것)

- **보장·과장 금지.** "상위노출 보장", "1위 보장", "무조건", "확실히 오른다", "100%" 같은 표현을 쓰지 않는다.
  오히려 "순위는 검색엔진이 정하며 누구도 보장할 수 없다 — 보장을 내거는 업체를 경계하라"는 톤.
- **어뷰징 권유 금지.** 가짜 리뷰, 대가성 리뷰, 별점 조건 이벤트, 지인 동원, 리뷰 구매를 권하지 않는다. 위험성을 알려준다.
- **키워드 스터핑 금지.** 메인 키워드는 제목·첫 문단·소제목 하나 정도에 자연스럽게. 같은 말 반복 금지.
- **업종 규정 반영.** 병원·의원(의료법 광고 규정, 효과 단정·치료 경험담 금지), 변호사 등 전문직(직역별 광고 규정),
  학원(교습비 게시), 체험단(대가 표시 의무, 표시광고법).
- **사실만.** 확인 안 된 통계·수치·사례를 지어내지 않는다. 숫자가 필요하면 "검색광고 키워드 도구로 직접 확인하라"고 안내한다.
- **실행 가능하게.** 순서·체크리스트·예시 문구·주의점. "~하는 것이 중요합니다"만 반복하는 글은 쓰지 않는다.
- 이전 글과 같은 구성·문장을 되풀이하지 않는다(유사도 35% 넘으면 검사에서 실패).
