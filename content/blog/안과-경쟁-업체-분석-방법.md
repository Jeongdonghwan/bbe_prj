"옆 건물 안과는 왜 전화가 더 많을까?" 이 질문에 감이 아니라 근거로 답하려면 비교표가 필요합니다. 안과 경쟁 업체 분석 방법은 거창한 도구 없이 휴대폰과 표 한 장이면 충분합니다. 한 시간 정도 시간을 잡고 아래 순서대로 채워 보세요. 목적은 남을 따라 하는 것이 아니라, 손님이 비교할 때 우리 병원에서 빠져 있는 정보를 찾는 것입니다.

## 비교 대상은 다섯 곳이면 된다

비교 대상을 너무 많이 잡으면 표만 커지고 결론이 흐려집니다. 아래 기준으로 다섯 곳을 고르세요.

- 손님이 칠 만한 검색어 두세 개(예: "역 이름 + 안과", "동네 + 안과 + 토요일")로 지도 검색을 했을 때 위쪽에 함께 나오는 곳
- 진료 범위가 비슷한 곳(검진 위주인지, 수술까지 하는지)
- 걸어서 혹은 차로 비슷한 거리에 있는 곳

검색은 로그인하지 않은 상태나 다른 기기로도 한 번 해 보세요. 평소 우리 병원을 자주 본 계정은 결과가 조금 다르게 보일 수 있습니다. 어떤 검색어가 실제로 많이 쓰이는지는 [무료 키워드 조회](/tools/keyword)에서 먼저 확인하고 시작하면 헛수고가 줄어듭니다.

## 비교표 양식

아래 표를 그대로 복사해 쓰면 됩니다. 칸마다 있다·없다, 혹은 짧은 메모만 적습니다.

| 항목 | 우리 병원 | A | B | C | D | E |
|---|---|---|---|---|---|---|
| 대표 사진(첫 장) 내용 | | | | | | |
| 사진 수·최근 업로드 시기 | | | | | | |
| 요일별 진료시간 표기 | | | | | | |
| 야간·주말 진료 | | | | | | |
| 의료진 소개 | | | | | | |
| 진료 항목·비급여 가격 안내 | | | | | | |
| 예약 방식 | | | | | | |
| 주차 안내 | | | | | | |
| 리뷰 수·답글 여부 | | | | | | |
| 소식 마지막 게시일 | | | | | | |

다 채운 뒤 "다른 곳은 대부분 있는데 우리만 없는 칸"에 표시합니다. 그 칸이 첫 번째 할 일입니다.

## 리뷰에서 읽어야 할 것

리뷰는 별점보다 내용을 봅니다. 경쟁 병원 리뷰를 최근 것부터 30개 정도 훑으면서 아래 세 가지를 메모하세요.

1. **칭찬이 반복되는 지점** — 대기 시간이 짧다, 설명이 자세하다, 검사 동선이 편하다 등
2. **불만이 반복되는 지점** — 주차, 대기, 전화 연결 같은 운영 문제
3. **손님이 쓰는 단어** — 손님이 병원을 부르는 말, 검사 이름을 부르는 방식

세 번째가 의외로 쓸모가 큽니다. 손님이 쓰는 말이 곧 검색어 후보이고, 우리 병원 소개글을 손님 언어로 고칠 단서가 됩니다.

## 분석 결과를 옮기는 방법

비교표에서 찾은 빈칸을 순서대로 채웁니다.

- 진료시간 표기가 부족했다면 요일별로 나눠 다시 적고, 검사 접수 마감 시간을 따로 표시합니다.
- 사진이 오래됐다면 외관, 접수대, 검사실 순서로 새로 찍어 올립니다. 환자가 나오는 사진은 동의를 받은 것만 씁니다.
- 경쟁 병원 리뷰에서 반복된 불만(예: 주차)이 우리 병원에서는 해결돼 있다면 그 정보를 소개글과 방문 안내에 분명하게 적습니다.

## 검색 결과 화면도 기록하기

비교표와 별개로, 검색어별 지도 결과 화면을 캡처해 날짜별 폴더에 모아 두세요. 검색어 하나당 한 장이면 됩니다. 캡처에서 볼 것은 세 가지입니다.

- 우리 병원이 몇 번째에 나오는지
- 위쪽에 광고가 몇 개 붙어 있는지
- 위에 나오는 병원들의 대표 사진이 어떤 종류인지(외관, 대기실, 의료진)

광고가 많이 붙는 검색어는 경쟁이 치열하다는 신호이고, 대표 사진 종류가 한쪽으로 몰려 있다면 우리 병원은 다른 종류로 눈에 띄게 할 여지가 있습니다. 이런 관찰은 한 번 볼 때보다 몇 달치를 모았을 때 훨씬 잘 보입니다.

### 진료 범위 차이도 적어 두기

라식·백내장 같은 수술을 하는 병원과 검진·일반 진료 위주의 병원은 손님이 다릅니다. 비교 대상 중 진료 범위가 우리와 다른 곳이 있다면 표에 따로 표시해 두고, 결론을 낼 때 가중치를 낮추세요.

## 하지 말아야 할 것

분석 결과를 광고 문구로 바로 옮기는 것은 조심해야 합니다. 의료광고에서 다른 병원과 비교해 우월하다고 말하는 표현은 금지돼 있습니다. "근처에서 가장", "타 병원보다" 같은 말 대신 우리 병원 사실만 적으세요. 경쟁 병원 사진이나 소개 문장을 그대로 베끼는 것도 저작권과 신뢰 양쪽에서 손해입니다.

## 석 달마다 다시 채우기

비교표는 분기마다 한 번 다시 채우면 충분합니다. 이전 표와 나란히 두면 경쟁 병원이 무엇을 바꿨는지, 우리 병원 순위가 어떻게 움직였는지 함께 볼 수 있습니다. 노출 순서에 영향을 주는 요소는 [안과 플레이스 상위노출 가이드](/learn/안과-플레이스-상위노출/)에, 업종 전반은 [안과 마케팅](/learn/안과-마케팅/)에 정리돼 있습니다.
