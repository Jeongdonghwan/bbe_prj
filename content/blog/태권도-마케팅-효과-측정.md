전단을 돌리고, 블로그를 쓰고, 플레이스를 손봤는데 무엇이 효과가 있었는지 모르겠다는 관장님이 많습니다. 태권도 마케팅 효과 측정은 거창한 도구가 필요하지 않습니다. 상담이 들어올 때마다 "어떻게 알고 오셨는지" 한 줄을 남기는 것에서 시작합니다.

## 왜 감으로는 안 되는가

도장 등록은 계절을 크게 탑니다. 방학 전, 새 학기 직전에는 아무것도 안 해도 문의가 늘고, 시험 기간이나 명절 무렵에는 줄어듭니다. 그래서 "이번 달 문의가 늘었다"만 보고 방금 바꾼 홍보 덕분이라고 판단하면 틀리기 쉽습니다. 같은 시기끼리, 같은 경로끼리 비교해야 합니다.

## 볼 지표 다섯 가지

1. **노출** — 스마트플레이스 통계의 조회 수, 블로그 방문 수
2. **행동** — 전화 걸기, 길찾기, 톡톡·예약 클릭 수
3. **상담** — 실제로 전화나 방문 상담을 한 건수
4. **체험 수업** — 상담 뒤 체험까지 온 건수
5. **등록** — 체험 뒤 정식 등록한 건수

위로 갈수록 숫자가 크고 아래로 갈수록 작아집니다. 어느 단계에서 크게 줄어드는지가 고칠 곳입니다. 조회는 많은데 전화가 적다면 플레이스 정보(시간표, 차량 운행, 수련비 안내)가 부족한 경우가 많고, 상담은 많은데 등록이 적다면 상담 내용이나 체험 수업을 돌아볼 차례입니다.

## 상담 경로 기록표

데스크에 아래 같은 표를 두고 상담이 들어올 때마다 한 줄씩 채웁니다.

| 날짜 | 아이 학년 | 알게 된 경로 | 체험 | 등록 |
|---|---|---|---|---|
| 11/3 | 초1 | 네이버 지도 | O | O |
| 11/4 | 7세 | 형제 소개 | O | - |
| 11/6 | 초3 | 아파트 게시판 | - | - |

이 표는 예시이며, 실제 칸은 도장 상황에 맞게 바꾸면 됩니다. 경로는 "검색", "소개", "전단", "현수막", "지나가다" 정도로 미리 정해 두어야 나중에 세기 쉽습니다. 보호자에게 물을 때는 "혹시 어디서 보고 연락 주셨어요?" 한 마디면 충분합니다.

## 검색 순위와 검색량도 함께 적는다

지도 검색에서 우리 도장이 몇 번째에 나오는지는 매주 같은 요일, 같은 위치에서 확인해 적어 두세요. "동네 이름 + 태권도", "동네 이름 + 어린이 태권도"처럼 보호자가 실제로 쓰는 말을 두세 개 골라 고정합니다. 어떤 말이 많이 검색되는지는 [키워드 조회](/tools/keyword)에서 확인할 수 있고, 도장용 키워드 고르는 법은 [태권도 키워드 찾기](/learn/태권도-키워드-찾기/)에 정리해 두었습니다.

마이마케팅으로 유입 캠페인을 돌린다면 등록하는 순간부터 일자별 순위가 자동으로 기록되므로, 시작 전 기준값과 진행 중 변화를 한 화면에서 비교할 수 있습니다. 순위가 어떻게 움직일지는 누구도 약속할 수 없으니, 기록을 보고 계속할지 멈출지를 정하는 용도로 쓰세요.

## 한 달 정리 예시

기록표를 한 달 모았다면 월말에 경로별로 세어 봅니다. 아래는 정리 방식을 보여 주는 빈 양식입니다. 숫자는 도장마다 다르니 직접 채워 넣으세요.

| 경로 | 상담 | 체험 | 등록 | 메모 |
|---|---|---|---|---|
| 네이버 지도·검색 | | | | 어떤 검색어였는지 |
| 소개 | | | | 소개해 준 관원 |
| 전단·현수막 | | | | 배포 지역 |
| 기타 | | | | |

이 표를 석 달 이어 붙이면 경로별로 상담이 등록까지 이어지는 비율이 보입니다. 전단은 상담은 적어도 등록 비율이 높을 수 있고, 검색은 상담이 많아도 비교만 하고 가는 보호자가 섞여 있을 수 있습니다. 어느 쪽이 낫다고 미리 정하지 말고 우리 도장 숫자로 판단하세요.

비용도 같은 표에 적어 두면 좋습니다. 전단 인쇄비, 현수막 게시 비용, 온라인 광고비를 경로 옆에 써 두면 등록 한 건에 얼마가 들었는지 대략 계산할 수 있습니다. 다만 등록 수가 적은 달에는 이 금액이 크게 흔들리니, 한 달 숫자로 경로를 끊기보다 분기 단위로 모아서 판단하는 편이 안전합니다.

## 숫자를 잘못 읽기 쉬운 경우

- 한 달에 등록이 서너 건이라면 한두 건 차이는 우연일 수 있습니다. 최소 석 달은 모아서 보세요.
- 두 가지를 동시에 바꾸면 무엇이 효과였는지 알 수 없습니다. 전단과 플레이스 개편을 같은 달에 하지 마세요.
- 소개로 온 등록은 홍보 효과가 아니라 기존 관원 만족도의 결과입니다. 따로 세어야 합니다.

수련비나 차량 운행 같은 정보는 보호자가 상담 전에 가장 궁금해하는 부분이니 플레이스에 숨기지 말고 적어 두는 편이 상담 단계를 줄여 줍니다. 홍보 전반은 [태권도 마케팅 가이드](/learn/태권도-마케팅/)에서 이어 볼 수 있습니다.
